# 图片资源

本目录保存网站图片的原始图集、拆分结果和映射元数据。应用运行时使用的资源位于仓库根目录的 `public/art/`。

## 目录

```text
source/                 原始图集，仅用于追溯和再加工
public/art/             从图集中整理出的 PNG 与 WebP 文件
manifest.json           素材尺寸、来源裁切框和角色／状态映射
素材清单.csv             便于人工筛选的素材清单
```

新增或替换图片时，应同步更新 `public/art/` 中的运行时版本以及相关映射代码。不要仅修改本目录后假设网站会自动采用新文件。

## 手机运行时图片

- `source/mobile-originals/` 保留压缩前的运行时素材，`source/mobile-portraits/` 保存用户提供的金蓝头像和边框原图；两者不会复制进发布目录。
- `public/art/`（仓库根目录）只使用手机版 WebP。背景长边最多 768px；头像、边框、角色图最多 192px；状态图最多 72px；阵营图最多 96px；剧本图最多 128px。较小原图不会放大，透明背景保留。
- 使用 Python + Pillow 执行 `python scripts/optimize-art.py` 可从保留的原图重新生成；不在每次构建时重复压缩。脚本输出 `assets/mobile-art-manifest.json`，记录实际尺寸和文件体积。
- 网站不再打包重复的原始 PNG；如需原始版本，请使用素材目录。不要把原图重新复制到根目录 `public/art/`。

## 使用规则

- 角色和状态图片用于辅助辨识，不能替代可读的角色名和状态文字。
- 未覆盖的角色必须保留文字或类别图案回退。
- 身份卡背对所有玩家保持一致，不能通过文件名、图片地址或 DOM 提前泄露身份。
- 玩家页面只依据个人展示投影选择素材；公开城镇不能读取真实身份或秘密标记。
- 图集中出现的生成文字和示例标签不是规则来源，不应直接用于界面文案。
- 素材不应被描述为官方角色图标或官方授权素材。
