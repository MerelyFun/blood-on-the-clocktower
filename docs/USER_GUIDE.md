# 使用指南

## 选择运行模式

| 模式 | 适用场景 | 数据位置 | 身份发放 |
| --- | --- | --- | --- |
| 本机主持 | 说书人使用一台设备记录对局 | 当前浏览器的 IndexedDB | 在说书人设备上依次展示 |
| 联机房间 | 玩家各自使用手机加入 | Supabase | 每位玩家只在自己的页面查看 |

本机存档不会自动同步到联机房间或其他域名。需要迁移时，先导出完整存档，再从首页导入；恢复操作会创建新对局，不会覆盖原对局。

## 说书人流程

### 1. 准备剧本

在“剧本工坊”选择基础剧本，或复制后增删角色。自制剧本可通过 JSON 导入；纸质或图片剧本可使用“图片转 JSON”，识别后必须人工核对角色名单。

剧本角色池、本局实际入袋角色和发给玩家看的身份是三层不同数据。修改剧本不会自动改写已经开始的对局。

### 2. 创建对局

在首页选择“我是说书人”，再选择本机主持或联机房间、剧本和普通玩家人数。联机房间要求说书人先使用持久账号登录。

导入完整存档时，同样先选择目标模式。导入后的副本会获得新的房间标识。

### 3. 安排玩家与座位

联机模式下，把二维码、邀请链接或六位房间码发给玩家。玩家提交昵称后，需由说书人在“邀请与入座管理”中批准并绑定座位。全部玩家入座后可锁定房间，阻止新的申请。

玩家更换浏览器、清除站点数据或丢失匿名凭据时，使用“替换该座位旧设备”重新绑定。旧设备随后失去该座位的读取和提交权限。

### 4. 配置并发放身份

在准备阶段设置每个座位的真实角色、真实阵营、展示角色和告知阵营。系统提供标准配比提示与随机候选，但不会替说书人执行角色能力带来的配比变化。

发牌前重点核对：

- 酒鬼、疯子等角色的真实身份与展示身份；
- 外来者数量修正和恶魔伪装；
- 固定分配或随机分配方式；
- 已入座玩家与座位绑定是否正确。

本机模式通过“本机展示身份”逐人查看；联机模式由玩家在自己的身份页查看并确认。

### 5. 主持对局

说书人工具有五个主要区域：

- “魔典”：查看座位、真实与公开生死、角色、标记和座位笔记。
- “夜晚”：按首夜或其他夜顺序处理任务，也可调整顺序、插入手动任务并记录结果。
- “计票”：记录提名、逐席投票、门槛、特殊票数、处决与死亡。
- “记录”：查看公开或私密事件、保存快照、导出备份和发布复盘。
- “剧本”：查看本局角色能力与传奇／奇遇规则。

醉毒、错误信息、疯狂、保护、死亡替代、角色继承和胜负均由说书人裁定。软件负责记录、提示和同步，不是自动规则裁判。

### 6. 结束与归档

结束对局时填写胜方。需要复盘时，仅发布希望玩家看到的角色与阵营；私信、说书人笔记和玩家私人笔记不会进入公开复盘。

建议重要对局至少保留一份完整存档。公开记录适合分享，但不能用于恢复完整魔典。

## 玩家流程

1. 打开邀请链接，或在首页选择“我是玩家”并输入房间码和昵称。
2. 等待说书人批准并分配座位。
3. 发牌后，在“我的身份”确认周围无人旁观，再翻开身份卡。
4. 在“私密信息”阅读说书人消息或回复选择请求。
5. 在“公开城镇”查看已公开阶段、座位和事件；在“剧本”查看本局角色池。
6. “私人笔记”只允许当前账号读取，说书人默认也看不到。

身份页在切出页面或一段时间后会自动遮挡，但这只是防误看措施，不能防止截屏、录屏或已看到的信息被转述。

## 功能边界

当前版本不包含自动角色能力引擎、自动胜负裁定、玩家实时举手投票、多人协同说书人、语音视频、完整离线多人同步或安装式 PWA。实验角色和复杂桌规可通过自制角色、标记、公开说明、手动夜间任务与特殊裁定记录处理。

联机服务有房间数量、消息数量、快照数量和请求体积限制。长局结束后应及时导出并归档，不要把房间当作无限聊天或附件存储。
