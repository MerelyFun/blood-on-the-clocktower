# 内容来源与许可

Blood on the Clocktower / 血染钟楼由 The Pandemonium Institute 创作。本项目是非官方辅助工具，与官方应用不存在隶属或授权关系。

项目自行创作的应用代码采用 [MIT License](../LICENSE)。MIT 许可只覆盖项目有权许可的代码，不覆盖游戏名称、商标、角色、规则资料或第三方素材。第三方依赖和字体遵守各自许可证。

## 项目内的游戏内容

仓库包含常用角色名称、ID、类别、基础剧本名单、夜序结构，以及自行撰写的简要机制提示。这些内容用于辅助主持，不能替代完整规则、官方勘误或说书人裁定。

项目没有复制官方付费应用源码，也不把导入 JSON 中的远程图片地址当作可直接加载的受信素材。公开发行、品牌使用和规则内容的适用条件应由部署者依据权利人的现行政策自行核对。

主要资料入口：

- [Blood on the Clocktower 官方网站](https://bloodontheclocktower.com/)
- [官方 Wiki](https://wiki.bloodontheclocktower.com/)
- [官方剧本工具](https://script.bloodontheclocktower.com/)
- [剧本 JSON Schema](https://release.botc.app/script-schema.json)
- [夜序数据](https://release.botc.app/resources/data/nightsheet.json)
- [角色数据](https://release.botc.app/resources/data/roles.json)

## 用户导入内容

导入自制剧本、角色定义或其他文本时，上传者负责确认其使用权限。项目会尽量保留未知扩展字段，但不会将其解释为可执行脚本。

## 图片资源

网站使用的界面图片位于 `public/art/`，原始整理资料位于 `assets/`。这些图片仅作为项目界面素材，不应被宣传为官方角色图标或官方素材库。详细目录见 [assets/README.md](../assets/README.md)。
