# 界面与组件约定

核心是可操作的魔典。桌面采用 176 px 左导航、中央座位环和 340 px 右侧任务/玩家详情；移动端导航位于顶部，座位改为列表，详情抽屉可关闭。

颜色：背景 #111315，表面 #191c20，边框 #303338，正文 #e9e5dd，次要文字 #8f959e，主要操作 #a74248，选中与提醒 #c6ad74，善良 #649ddd，邪恶 #d26e76。角色类别和阵营均有文字，不单独依赖颜色。字号正文 14 px，控件 13–14 px，标题 28–34 px，主要标题使用系统宋体/衬线字体。间距 4/8/12/16/24/32，圆角 6/10/16 px。图标采用 Lucide 1.7 px 线宽，角色令牌为原创文字徽章，不携带官方图像。

组件：AppShell、Button、Modal、Field、RoleToken、SeatRing、SeatInspector、NightPanel、VotePanel、EventPanel、ScriptEditor、SetupPanel、PlayerRoom。表单支持键盘焦点，危险操作先展示目标与结果；实时同步中禁用重复提交。轻量过渡遵从 prefers-reduced-motion。

初始概念图只作为布局参考，图中的示例规则文案不作为角色规则来源。必要流程扩展包括房间入口、剧本编辑、开局、玩家身份和复盘，沿用同一套组件。

按用户要求，本次未进行浏览器视觉检查或功能测试，不作视觉一致性已验证的声明。
