# 接入位置与最小代码示例

本目录是可选接入示例，不是已经应用或测试通过的补丁。原始源码未被修改。先复制 `public/art`，再按需要选择入口接入；不必一次改完。

## 路径

`art.ts` 放入项目的 `src/lib/art.ts`，示例根据项目 `vite.config.ts` 的 base 配置，通过 `import.meta.env.BASE_URL` 拼接静态资源，不直接写死根路径。这里的映射只引用本地静态文件，不从导入剧本的任意 URL 拉取图片。

## 角色小图：src/components/ui.tsx:16

把 `RoleToken.example.tsx` 中的组件实现按需要替换原来的 `RoleToken`，也可以仅参考其中的图片与文字回退部分。原文件已导入 `useState`，不要重复声明导入。

接入 CSS 追加 `art.example.css` 中对应段落。图片加载失败会回退首字；未覆盖的角色走类别图。展示文本、阵营名称、角色能力与角色选择逻辑均保留。

**重要：** 此函数本身不是权限控制。玩家身份卡只在现有 `revealed` 分支下传已有的 `p.role`，未翻牌分支不渲染角色图；公开座位也不能额外传真实 `roleId` 来取图。

## 身份卡背：本轮不提供默认铺满补丁

当前 `.identity-card` 普通尺寸约 340 × 370 px，而卡背素材原生只有 126 × 178 px，宽高比例也不同。因此本轮只交付视觉参考和小尺寸背景，不提供把它强行拉满的默认 CSS。高清卡背另按规格生成后再替换。

## 手工核验清单

复制完成后确认资源不 404；角色首字回退有效；库内所有名字仍可读；未翻牌时没有角色图；公开视图没有隐藏身份图；原有30秒自动遮挡、失焦遮挡不被修改；桌面与窄屏控件不被图片遮挡。这些是接入后的验收事项，本素材包没有声称已经运行网站完成这些检查。
