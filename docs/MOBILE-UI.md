# 手机羊皮纸界面（2026-09-11）

本次按手机使用重排界面。以浅色羊皮纸、深墨文字、酒红主按钮为统一视觉；角色继续使用项目原有图片，不改变游戏数据或规则。

## 操作入口

- 首页切换「我是说书人 / 我是玩家」，房间名称为选填折叠项。
- 魔典保留公开视图、笔记、更多与阶段推进；座位为大角色图标单列列表。
- 「更多」集中邀请入座、标记、座位调整、旅行者、展示身份、暂停、公告、快照、计时与结束对局。
- 底栏为魔典、夜晚、计票、记录、剧本。其他页收紧顶部以显示更多内容。
- 配牌说明、导出备份、高级联机配置默认折叠；必要的发牌、公开信息、处决和结束确认保留。
- 笔记仍须点击保存，已保存状态有明确反馈。字体放大设置保留。

## 视觉与功能验收

内置浏览器返回 `nodeRepl.fetch request failed`，改用 Playwright 驱动本机 Edge。检查 360、375、390、430 像素手机宽度，页面没有横向溢出。主屏截图按 390 × 844 验收。

逐图对照设计概念和浏览器截图：

| 项目 | 实现与修正 |
| --- | --- |
| 纸底 | 使用独立生成、低对比的纸纤维纹理，压缩成 9.8 KB WebP；文字和按钮均为真实 DOM |
| 色彩 | 纸色 #f2e8d3、墨色 #30271f、酒红 #782f3b；清除列表、弹窗、表单的旧深色残留 |
| 排版 | 标题采用宋体风格，正文与表单明确字号；修正手机旧样式隐藏阶段的问题 |
| 座位 | 60px 角色图标、单列行、善恶角色名分别蓝红色；修正列表名称错列 |
| 控件 | 常用按钮至少 48px 高，底栏图标 26px；弹窗使用底部面板和安全区 |
| 信息层级 | 去掉重复魔典标题、宣传说明、环/列表切换与重复夜间面板，保留状态与风险提示 |

相对于概念图的有意调整：保留用户已有角色美术与品牌图标；公开视图、笔记、更多并排，以便一键隐藏秘密；长房间名称允许换行；真实存活状态与标记随数据展示。首页和其他页沿用同一设计系统。未将概念图片当成网页。

实测本机创建 → 添加旅行者 → 发身份 → 切换阶段 → 提名计票 → 处决 → 下一夜 → 完整导出与恢复副本；全局笔记保存后刷新恢复、座位笔记保存、更多工具、各底栏入口均通过。公开视图没有私密角色图标。无浏览器运行时错误。类型检查、34 项测试与生产构建通过；原有 JS 大包提示仍存在。

## 图片制作

使用内置 Image Gen，生成手机魔典参考图及独立纸纹理。生产资源：`public/art/decoration/parchment-texture.webp`。

纹理提示：seamless fine ivory parchment paper, pale warm cream #f2e8d3, subtle natural fibers, clean evenly lit low-contrast surface for dark mobile UI text; no text, objects, borders, folds, burnt edges or dark spots.

设计提示：390 × 844 中文手机说书人魔典，浅羊皮纸、墨色文字、酒红按钮，大角色图标单列座位，阶段与公开视图、笔记、更多、进入白天；底栏魔典/夜晚/计票/记录/剧本，48px触控区域，少装饰与说明文字。
