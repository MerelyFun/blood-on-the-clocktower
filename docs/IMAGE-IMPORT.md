# 图片转剧本 JSON

入口：剧本工坊 → 图片转 JSON。

1. 选择 JPG、PNG 或 WebP 剧本图片，最大 15 MB。
2. 点击「开始识别」。两栏 / 三栏图片可在识别选项中指定栏数；繁体图片可以勾选繁体中文。
3. 对照原图核对角色，删除误选、搜索补充遗漏角色。也可展开「识别文字 / 手动校正」修改后重新匹配。
4. 填写剧本名，确认角色列表，然后下载通用 JSON，或放入剧本工坊继续编辑、保存、开局。

通用 JSON 沿用现有导出器：数组首项为 `_meta`，包含剧本名称与作者；后续是角色 ID 对象，自制角色保留完整定义。不会把剧本图片、OCR 原文或房间存档混入 JSON。

识别依靠已有角色目录匹配，不会自动编造自制角色能力。图片里的小字、花体、倾斜拍照、图标遮挡可能造成漏识别或误识别；核对后才能下载。有未知自制角色时，可先放入工坊手动补全。没有匹配角色时允许进入工坊创建角色，禁止下载空剧本。

## 运行方式

- 图片在浏览器中处理，不上传至服务器，无需 API Key 或 Supabase 变更。
- Tesseract.js 7.0.0 按需加载；WASM、Worker、简繁语言包由本站提供。首次识别需要下载数 MB 资源，后续语言数据使用浏览器缓存。
- 原图按尺寸缩放以控制手机内存；每栏分别进行标题与文本块识别，合并去重后交由用户核对。
- 支持取消、180 秒超时、加载失败提示；关闭弹窗终止识别并释放图片资源。
- `npm run dev` 和 `npm run build` 会先运行 `scripts/prepare-ocr.mjs`，从锁定依赖复制 OCR 资源。`public/ocr/` 为生成目录，不提交。

## 验证

40 项测试通过，包括角色名空格、列表前缀、重复去除、不把能力正文引用自动当作角色、未知角色不猜测、通用 JSON 往返导入。

通过 Playwright + Edge 实际运行 OCR，单列与两栏中文样图均匹配 7 个预期角色，并验证确认门槛、JSON 下载、放入工坊、手动增删、取消、网络加载失败提示，以及手机窄屏无横向溢出。此验证不代表任意照片都能完整识别。

## 字体与来源

全站使用寒蝉全圆体，保留羊皮纸主题，按钮与表单边角同步圆润化。字体随站点托管，无需访问外部字体服务；字体授权见 `public/fonts/OFL-ChillRound.txt`。

- 字体：[Warren2060/ChillRound](https://github.com/Warren2060/ChillRound)，v3.0 TTF 无字形改动压缩为 WOFF2。
- OCR：[Tesseract.js 文档](https://github.com/naptha/tesseract.js/blob/master/docs/api.md)。语言包由锁定的 `@tesseract.js-data` 包提供。
- 繁简转换：[OpenCC-JS](https://github.com/nk2028/opencc-js)，仅在繁体识别后按需加载。
