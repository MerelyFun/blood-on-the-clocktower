# 本版范围与操作边界

## 已提供的实现

本版覆盖选剧本、改角色池、开局配板、联机私密身份、说书人主持、手动夜间裁定、提名计票、独立处决与死亡、旅行者、日志存档和恢复的完整操作入口。

内置三大基础剧本的 72 个普通角色、15 个旅行者，以及若干常用传奇 / 奇遇角色。实验角色和其他自制角色可通过包含完整角色定义的 JSON 导入，或自行新增。只给一个未知角色 ID 时会保留条目，要求补全后才能发给玩家。

内置能力文字是简要提示，不是逐字复刻的完整规则或官方译本。全局夜序基于调研时的官方 nightsheet；导入的 firstNight / otherNight 数值保留，实际角色进入任务后可继续手动改序。

## 由说书人负责的规则

没有自动角色能力引擎或 AI 裁判。醉毒、错误信息、疯狂、保护、死亡替代、角色继承与胜负均由说书人操作。这个边界是计划中的人类主持模式：软件记录与提示，不决定真实信息。

- 酒鬼：真实角色选酒鬼、展示角色选镇民，检查是否重复占用展示角色。
- 疯子：真实善良与展示邪恶分别维护；首夜信息和选择转告恶魔需分别发送。
- 麻脸巫婆 / 舞蛇人等：更正角色、真实阵营、展示角色、告知阵营分别填写，不自动互相覆盖。
- 僵怖：允许真实存活、公开死亡。
- 守鸦人 / 贤者：死者的夜间条目仍可查看，必要时插入手动任务。
- 间谍：通过“魔典快照”选择允许给出的座位与标记，预览后发给指定玩家。
- 男爵、方古、教父等：手动修正四类角色数量，不自动套用基础配比。
- 官员、窃贼、巫毒师等：在特殊计票中填写修正票数、门槛、是否消耗死者票及原因。
- 额外提名 / 处决：勾选特殊规则，并留下裁定原因。
- 传奇 / 奇遇角色：把角色加入剧本，勾选“本局启用”，具体桌规通过公开说明和手动任务执行。

## 数据容量

当前服务端限制：每位说书人最多 30 个房间、每房间最多 20 个座位、40 个待处理加入申请、每用户最多 5 个同时待批准房间、每分钟最多 8 次加入尝试。单局最多 500 条私信、200 个标记、100 个夜间任务、最近 8 个快照。Edge 请求体最多 4 MB。非常长的对局请导出后归档，避免把工具当作无限聊天或附件存储。

请求在 20 秒后超时；不能确定服务器是否完成的请求，在当前标签页保存原操作 ID，可用“安全重试上次提交”确认。刷新本身不代表取消该请求。玩家私人笔记保存失败时，会在当前标签页保留草稿；其他尚未点击保存的输入不会自动同步。
