# 使用指南

## 选择运行模式

| 模式 | 适用场景 | 数据位置 | 身份发放 |
| --- | --- | --- | --- |
| 本机数据库（开发默认） | 同一 Wi-Fi 内玩家各自使用手机加入 | 运行服务电脑上的 SQLite | 每位玩家只在自己的页面查看 |
| 仅此浏览器 | 说书人使用一台设备记录对局 | 当前浏览器的 IndexedDB | 在说书人设备上依次展示 |
| 云端联机房间（可选） | 通过互联网加入 | Supabase | 每位玩家只在自己的页面查看 |

运行 `npm run dev` 后，本机数据库无需登录 Supabase 即可使用。电脑访问 `http://localhost:5174/`；手机连接同一 Wi-Fi 后访问 `http://电脑的局域网IP:5174/`。建议说书人也使用局域网地址，创建后分享该地址下的邀请链接，确保所有设备访问同一服务。电脑需保持开机且服务运行。

本机数据库的数据在服务重启后仍保留。设备身份由当前浏览器保存，切换浏览器、IP、端口或清除站点数据可能被视为新设备；`localhost` 和局域网 IP 也属于不同来源。设备凭据不是云端账号。

三种模式的数据不会自动互相同步；浏览器存档也不会自动跨域名同步。需要迁移时，先导出完整存档，再从首页导入；恢复操作会创建新对局，不会覆盖原对局。

## 说书人流程

### 1. 准备剧本

在“剧本工坊”选择基础剧本，或复制后增删角色。自制剧本可通过 JSON 导入；纸质或图片剧本可使用“图片转 JSON”，识别后必须人工核对角色名单。

新建时点击“新建剧本”，先输入名称，再添加角色。选角页直接按类别显示完整已选名单，无需打开弹窗；点击名称查看能力，点击旁边的 × 移除；类别旁的数字是该类别已选数量。“完成选角”返回总览，仍需点击“保存剧本”或“用此剧本开局”。作者与简介可稍后补充。

剧本角色池、本局实际入袋角色和发给玩家看的身份是三层不同数据。修改剧本不会自动改写已经开始的对局。

### 2. 创建对局

在首页选择“我是说书人”，再选择运行模式、剧本和普通玩家人数。开发预览默认选择“本机数据库”，可以直接创建；“仅此浏览器”用于单设备主持。使用 Supabase 云端联机房间时，说书人仍需先使用持久账号登录。

导入完整存档时，同样先选择目标模式。导入后的副本会获得新的房间标识。

### 3. 安排玩家与座位

本机数据库和云端联机模式下，把二维码、邀请链接或六位房间码发给玩家。玩家提交昵称后，需由说书人在“邀请与入座管理”中批准并绑定座位。全部玩家入座后可锁定房间，阻止新的申请。

玩家更换浏览器、清除站点数据或丢失匿名凭据时，使用“替换该座位旧设备”重新绑定。旧设备随后失去该座位的读取和提交权限。

### 4. 配置并发放身份

在准备阶段设置每个座位的真实角色、真实阵营、展示角色和告知阵营。系统提供标准配比提示与随机候选，但不会替说书人执行角色能力带来的配比变化。

发牌前重点核对：

- 酒鬼、疯子等角色的真实身份与展示身份；
- 外来者数量修正和恶魔伪装；
- 固定分配或随机分配方式；
- 已入座玩家与座位绑定是否正确。

“仅此浏览器”模式通过“本机展示身份”逐人查看；本机数据库和云端联机模式由玩家在自己的身份页查看并确认。

### 5. 主持对局

说书人工具有五个主要区域：

- “魔典”：查看座位、真实与公开生死、角色、标记和座位笔记。
- “夜晚”：按首夜或其他夜顺序处理任务，也可调整顺序、插入手动任务并记录结果。
- “计票”：记录提名、逐席投票、门槛、特殊票数、处决与死亡。
- “记录”：查看公开或私密事件、保存快照、导出备份和发布复盘。
- “剧本”：查看本局角色能力与传奇／奇遇规则。

醉毒、错误信息、疯狂、保护、死亡替代、角色继承和胜负均由说书人裁定。软件负责记录、提示和同步，不是自动规则裁判。

### 6. 结束与归档

结束对局时填写胜方。需要复盘时，仅发布希望玩家看到的角色与阵营；私信、说书人笔记和玩家私人笔记不会进入公开复盘。

建议重要对局至少保留一份完整存档。公开记录适合分享，但不能用于恢复完整魔典。

## 玩家流程

1. 打开邀请链接，或在首页选择“我是玩家”并输入房间码和昵称。
2. 等待说书人批准并分配座位。
3. 发牌后，在“我的身份”确认周围无人旁观，再翻开身份卡。
4. 在“私密信息”阅读说书人消息或回复选择请求。
5. 在“公开城镇”查看已公开阶段、座位和事件；在“剧本”查看本局角色池。
6. “私人笔记”只允许当前身份读取，说书人默认也看不到。本机数据库模式保存在电脑 SQLite 中，并按设备身份隔离。

身份页在切出页面或一段时间后会自动遮挡，但这只是防误看措施，不能防止截屏、录屏或已看到的信息被转述。

## 玩家笔记：围着桌子记，按天回看

主导航的“笔记”可新建独立记录，也可打开关联房间的笔记；房间里的“私人笔记”使用同一本记录。登录、退出及阅读偏好统一放在“设置与账号”。

独立记录无需登录，默认 7 人，可以调整人数、添加旅行者、选择剧本或直接按座位号开记；姓名可稍后填写。每人可标记一个“主角色”，并多选“额外状态”，包括其他候选身份、醉酒、中毒、善良、邪恶，也可输入自定义标记。同一角色可标记给多人。主角色与额外状态直接显示在桌面座位上。

点座位打开玩家面板，直接查看此人的所有信息，按天分组，天内再分夜晚、白天，最新日期在前；可随时添加信息。新条目默认当天，编辑时用“记录日期”选择过去某天补记，并保留夜晚或白天标识。桌面使用当天的角色与状态；头像为圆形，主身份同时用文字标明。页面顶部不再切换日期；独立记录可在桌心说书人下方点“进入下一天”，关联房间则跟随房间天数。

桌面下方统一为“笔记”，将原“公共信息”和“随手记”合在一起按天、昼夜分组，用来记录公开事件、自己的信息、推理与问题，原有文字全部保留。**整本笔记都属于私人记录，不会发送给其他玩家或进入公开复盘。** 关联房间只自动接收当前玩家可见的座位、阶段和公开事件，自动条目标为“房间公开记录”且不可修改，自己的补充不会改变房间状态。

编辑会自动保留本机草稿并尝试同步；离开前注意保存状态。“已保存在此设备，待同步”表示服务端尚未确认，恢复连接后可重试。独立笔记存放在当前浏览器；本机数据库房间笔记存放在电脑 SQLite，并按设备身份隔离；云端房间笔记使用 Supabase 的私人存储。更换浏览器、域名、IP 或端口不会自动带走浏览器笔记，需要先导出再导入。

笔记可改名、归档和导出备份，结束对局后仍可补记复盘。旧版全文保留在“未分日旧笔记”，不会自动猜测日期。笔记没有遮挡开关，切到后台后返回也无需解除遮挡。

## 功能边界

当前版本不包含自动角色能力引擎、自动胜负裁定、玩家实时举手投票、多人协同说书人、语音视频、完整离线多人同步或安装式 PWA。实验角色和复杂桌规可通过自制角色、标记、公开说明、手动夜间任务与特殊裁定记录处理。

联机服务有房间数量、消息数量、快照数量和请求体积限制。长局结束后应及时导出并归档，不要把房间当作无限聊天或附件存储。

笔记条目使用交替浅色气泡，日期与昼夜仅显示在分组标题。编辑时插入座位只显示“几号”，内部保留稳定玩家引用。桌面上方的旋转按钮可改变观看方向并保存，座位编号和玩家关联不变。

玩家面板顶部可直接点击名字修改笔记中的称呼，点击主身份更换角色；只影响本人的笔记。标签中可选死亡和死者票已用，关联房间的生死与票状态由房间同步。面板不再显示“全部记录”、状态历史和“玩家与公开状态”折叠区。笔记气泡长按后可选重点、编辑或删除；电脑可右键，键盘可聚焦后按 Enter 或 Shift+F10。
